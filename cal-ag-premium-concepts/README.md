# CAL-AG Premium Homepage Concepts

Two high-fidelity, responsive homepage directions created for CAL-AG Enterprises, Inc.

- **American Fieldcraft** — cinematic, heritage-led, editorial.
- **Precision Yellow** — technical, energetic, product-led.

## Review

Open `index.html`, then choose either design direction. These are design concepts only and do not modify the live CAL-AG website.

## WordPress implementation

The concepts are structured to translate cleanly into a custom WordPress block theme or a performance-focused builder implementation. Product, application, parts, and company modules can map to reusable blocks and custom post types.

Photography supplied by the client. Company history and contact details are based on the current CAL-AG website.
